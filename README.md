
# Question Bank MVC (TypeScript, Express, MongoDB, Socket.IO)

This is a starter project created automatically. Features:
- JWT auth (register/login)
- MVC structure (controllers/services/models/routes)
- Socket.IO integration
- Winston logger; logs DB writes to logs/app.log
- Environment config (dev/prod)

Usage:
1. Copy `.env.example` to `.env` and set values.
2. npm install
3. npm run dev
